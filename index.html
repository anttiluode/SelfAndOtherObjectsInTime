Gate 2 — no agent ID

The mechanism is no longer handed agent_id. It receives noisy continuous identity vectors occupying actor, patient and perspective roles. The same identity can move between roles; SELF is recognized only by similarity to the protected control anchor.

The next weakness is obvious

Gate 2 still supplies the roles themselves: actor, patient, perspective, object and τ. The next gate should make the mechanism infer a relation from a temporal stream rather than receiving a clean relational tuple. After that, τ itself should stop being handed in.
