Why time is already part of the address

The memory key binds agent + object + τ, where τ is position inside the current event. The same object relation at a different temporal address is therefore a different write. Later gates can replace this handed-in τ with internally generated phase, elapsed-time populations, boundaries, and propagating fields.

Mechanism toy, not a claim about consciousness or a one-to-one brain model. Deterministic gate receipt: results/gate1.json.
